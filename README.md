# Tugas-statge
kuis statge
Analisis Nearest Neighbor Analysis (NNA)

Proyek ini menganalisis pola persebaran titik menggunakan metode Nearest Neighbor Analysis (NNA).

Hasil Visualisasi

- "hasil_nna.png" — Pola sebaran titik dan garis tetangga terdekat.
- "hasil_jarak_tetangga.png" — Distribusi jarak tetangga terdekat.
- "hasil_klaster.png" — Peta sebaran titik berdasarkan kelompok.
- "hasil_kde.png" — Peta kepadatan titik menggunakan KDE.
- "hasil_titik_terpencil.png" — Indikasi titik terpencil berdasarkan jarak tetangga terdekat.
